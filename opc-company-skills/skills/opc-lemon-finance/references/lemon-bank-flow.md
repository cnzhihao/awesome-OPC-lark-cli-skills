# 银行流水与银企互联

## 适用范围

查看银行日记账、准备或确认智能获取流水、检查账户和银企互联绑定状态。任何资金划转、付款和凭证动作都不在本流程内。

## 页面路径

`资金 → 银行日记账` 查看已有流水；`资金 → 账户设置 → 银行存款` 检查账户配置；`资金 → 银企互联` 检查银行授权和绑定状态。

## 查看已有流水

1. 执行 `lemon-context` 检查。
2. 核对银行账户的脱敏标识、币种、开始/结束日期和当前余额。
3. 使用摘要、交易日期、金额、对手方和收支方向筛选；保留筛选条件。
4. 读取交易状态和是否已有凭证关联，但不点击“关联凭证”或“生成凭证”。
5. 以“交易日期 + 账户脱敏标识 + 金额 + 摘要 + 对手方”作为流水候选幂等键；金额相同不能单独视为重复。

## 智能获取流水

“智能获取流水”是可能把银行流水或电子回单写入柠檬云的导入动作。点击最终获取前展示：

```text
银行账户：<银行/账户末四位>
日期范围：<开始至结束>
数据类型：<流水/电子回单>
已有记录：<数量>
预计影响：<导入到银行日记账，不生成凭证>
```

用户明确确认后才执行一次获取。日期范围上限、可获取历史月份和银行接口提示以当前页面为准；不要输入网银密码或代做银行登录。获取后重新查询并核对新增数量、重复项、余额和失败提示。

## 银企互联

银企互联可能要求公司名称、统一社会信用代码、银行账号、客户号、账户号、网银登录和 UKey 授权。本 Skill 只允许查看“已绑定/未绑定”状态并整理待准备资料；不输入凭据、不读取 UKey、不点击“立即授权”。

## 禁止动作

禁止新增或批量修改日记账、内部转账、付款、收款确认、关联凭证、生成凭证、删除流水和通过手工改余额掩盖差异。

## 输出

```text
账户：<银行/末四位>
范围：<日期>
已有流水：<数量>
获取动作：<未执行/已确认并执行/失败>
新增及重复：<数量>
余额核对：<通过/差异/无法判断>
异常：<接口、权限、未知对手方等>
```
