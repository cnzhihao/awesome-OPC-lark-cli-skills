# 审计、安全与幂等检查

## 操作日志

需要追溯时查看柠檬云的操作日志或当前页面状态，记录：时间、公司/账套、入口、查询范围、动作级别、结果、异常和用户确认文本。只记录完成任务所需的最小信息。

## 幂等原则

- 发票：发票代码/号码或数电发票号码 + 开票日期 + 价税合计；若号码不可用，再增加客户/供应商和项目。
- 银行流水：账户脱敏标识 + 交易日期/时间 + 金额 + 摘要 + 对手方 + 收支方向。
- 开票：客户税号 + 业务单据号 + 项目 + 金额 + 税率 + 开票期间。
- 任何批量动作先统计候选数，执行后回查结果数；数量不一致时停止，不重复点击。

## 敏感信息

对用户汇报时默认遮盖统一社会信用代码中段、银行账号中段、税号、发票完整号码、账户余额和个人联系方式。若用户确实需要核验，应在当前会话内最小化展示，不写入本地文件或外部系统。

## 纠错原则

发现重复、金额差异、期间错误、错误客户、错误税率或状态不一致时：

1. 保留证据和筛选条件。
2. 停止任何后续写入。
3. 说明可能影响和需要人工确认的最小修正动作。
4. 不自行删除、红冲、作废、反审核、改余额或生成凭证。

## 结果分类

结果必须明确标记为：`已查看`、`已准备草稿`、`已获取/已写入`、`已提交`、`失败` 或 `未执行`。页面被打开不等于动作已完成；按钮被点击但结果未复核时标记为“结果待确认”。
