# 柠檬云上下文与登录检查

## 目标

在任何财务操作前确认当前 Chrome 会话确实对应用户要处理的柠檬云公司、账套和会计期间。不要从上一次任务或浏览器标题推断上下文。

## 检查顺序

1. 确认使用的是用户指定的已登录 Chrome 账号；若指定“报税”账号，只使用该会话。
2. 确认页面域名和产品名称是柠檬云财务或柠檬云发票。
3. 读取顶部公司名称、账套、会计期间；记录目标日期范围。
4. 检查当前用户是否已经登录；若显示“税局未登录”“网银未绑定”或需要认证，不把它当作登录失败以外的信号，也不代用户授权。
5. 记录当前页面和筛选条件，作为结果复核的基线。

## 已观察到的功能入口

不同账套、版本和权限可能不同，应以当前页面为准：

- 资金：现金日记账、银行日记账、内部转账、票据管理、资金报表、核对总账、收支类别、银企互联、账户设置。
- 发票：一键取票、销项发票、进项发票、费用单据、发票资金一览表、发票风险分析。
- 设置：关联云发票、操作日志以及其他账套和权限设置。

## 输出

```text
公司/账套：<名称>
期间：<会计期间>
会话：<已登录/未登录/需要用户处理>
当前页面：<入口>
目标范围：<日期、账户、票种>
可执行级别：<只读/可准备草稿/等待确认>
```

## 失败处理

- 公司、账套或期间不一致：停止，不切换账套替用户猜测。
- 页面要求密码、验证码、税局登录、银行登录或 UKey：停止，让用户在页面中自行完成。
- 页面打开到新标签或出现营销弹窗：只保留业务页面，不能因弹窗改变任务范围。
- 账号已退出：报告登录状态，不索要或保存登录凭据。
